# lesson06-dp

《人工智能程序设计与实践》第 6 次课作业，包括凑硬币、0-1 背包、容量变式、必选约束、自动化测试、进度报告和独立研究。

## 运行方法

本项目只使用 Python 标准库，建议使用 Python 3.10 或更高版本。

```bash
python main.py
python -m unittest -v
```

## 验收检查点

- 面额 `[1, 5, 11]`、金额 `15`：贪心为 5 枚，动态规划为 3 枚。
- 1000g 背包：最大重要度 315，选择睡袋、食物、水具，总重 1000g。
- 800g 背包：最大重要度 255，选择炉具、睡袋、水具，总重 800g。
- 1000g 且炉具必选：最大重要度 295，选择炉具、睡袋、食物，总重 950g。

动态规划的结果还由 `test_algorithms.py` 中的暴力枚举独立核验，避免只用同一种算法“自己证明自己”。

## 文件说明

- `coin_change.py`：贪心与动态规划凑硬币。
- `knapsack.py`：0-1 背包、回溯组合和必选物品约束。
- `main.py`：打印全部课堂检查点、dp 表最后一行和回溯过程。
- `test_algorithms.py`：标准库 `unittest` 验收测试与暴力核验。
- `progress.md`：进度报告。
- `research.md`：三项独立研究任务。
